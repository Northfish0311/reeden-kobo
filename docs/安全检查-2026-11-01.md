# 公开项目安全检查（2026-11-01）

## 范围和方法

清理前基线为当时公开 main / v0.7.3。读取 GitHub 广告的全部引用（main 与 v0.7.0–v0.7.3），新建公开 mirror，检查完整可见历史：9 个 commit、179 个 blob、63 个 tree、3 个 annotated tag 对象。下载当时 4 个 Releases 的全部 8 个 ZIP，逐成员扫描；另检查本地 2 份原历史 bundle、5 份旧本地适配层 ZIP，以及设备应用备份目录中私人数据和 SSH 配置的存在性。

扫描包括私钥标记、常见 GitHub token、AWS access key 格式、真实设备内网地址及本机用户路径；结合文件名和人工复核。公开构建脚本内用于阻止路径泄露的正则命中属于误报，不是一个真实私人目录。没有把模式扫描当作“所有秘密都不存在”的证明；未将读取私人书籍或公开备份作为审计方式。

## 发现与处理

| 区域 | 发现 | 处理/边界 |
|---|---|---|
| 公开历史和 8 个发布 ZIP | 未发现上述凭证、实际设备地址或真实本机路径 | 构建路径检测规则的模式命中已人工排除；新版本另核对附件 |
| Git 作者元数据 | 使用个人邮箱，可识别所有者身份；不是访问凭证 | 所有者明确授权改用 noreply 并改写受影响提交及标签，见 [历史说明](历史清理.md) |
| 两份本地原历史 bundle | 含清理前的调试构建路径及旧内网示例 | 保留作恢复备份，不公开，不把原始扫描结果上传 |
| 设备应用升级备份 | 存在阅读数据及 SSH 配置 | 保留，不下载/删除私人内容；不应公开分享 |
| 本地诊断私钥 | 本地存在，权限 0600；未纳入公开仓库或附件 | 保留现有管理通道，不公开；本轮未发现其公开，不宣称已轮换 |
| 旧发布安装器 | 存在 ZIP/TAR/ar 路径、链接和格式校验不足 | v0.7.4 加固并增加回归；旧版本加安全升级警告 |
| Bullseye 固定运行库 | 免费 LTS 已结束；固定哈希不会自动打安全补丁 | 已披露并提出迁移门槛，尚未迁移或完成逐项 CVE 可利用性审计 |

真实凭证若有公开证据，应撤销/轮换；路径与作者邮箱清理本身不能代替凭证轮换。旧下载、缓存、Actions 记录、已经取得的副本和原提交链接不受本次历史改写完全控制，不能宣称全网抹除。

## 安装器回归

覆盖 ZIP 与 Debian TAR 的绝对路径、`..` 越界、反斜杠/盘符、Windows 设备名与 ADS、大小写冲突、文件用作父目录、特殊文件、目标目录中已有符号链接、链接读取根目录外文件，以及 ar 负长度/截断/重复数据成员。合法相对软/硬链接只在根目录内物化为普通文件；测试包含超过四层的合法链。

使用真实官方 Kindle 1.43.2+791 ZIP 和当前固定 Debian 包完成解包与组包，检查没有因拒绝不安全格式而破坏当前依赖。此验证不意味着任意归档都无风险，也不限制恶意归档的磁盘/CPU 资源消耗；最终包仍须通过来源和白名单校验。
