## 早期分支修改（2026-11-03）

1. USB 机型、NickelMenu、活动会话锁和升级前提检查提前到官方包下载与组包之前；实际写入前重复检查。
2. 新增 `python install.py --check` 只读检查，可指定 `--kobo-mount`。不联网、不组包、不写入设备、不输出设备序列号。
3. 增加 14 项自动测试、三平台 USB CI 覆盖和中文使用说明。
4. 提供 Windows/macOS/Linux “一键更新”入口，自动选择 USB 保留数据升级、获取缺失的官方包；更新前后核对同一设备，不把更新入口当作全新安装。用户仍需先下载新版 ZIP，此功能不是电脑端工具的在线自升级。
5. 官方下载先在临时目录接收，校验成功后再原子替换正式缓存；下载中断、白名单校验失败不会把本次下载变成坏缓存。保留原白名单和许可边界。
6. 补充 10 项一键更新与下载缓存测试；新增启动脚本纳入桌面入口回归。

功能改进已提交至 [上游 PR #1](https://github.com/SSNQ/reeden-kobo/pull/1)，由原作者决定是否合并。本 Fork 专属的首页与本声明不包含在该功能 PR 内。

本轮本地环境为 Windows / Python 3.12，使用临时模拟目录，不是真实 Kobo USB 盘：

- 原有一键安装/保留数据升级测试通过。
- 卸载测试：10 项中 9 项通过，1 项按平台跳过；归档安全测试：8 项中 6 项通过，2 项按平台跳过。
- 中文路径下 Windows 安装/更新/卸载启动脚本的帮助与错误参数退出码测试通过。
- 其余平台、C 与 QEMU 验证以 [对应提交的 CI 结果](https://github.com/Northfish0311/reeden-kobo/actions/workflows/ci.yml) 为准。
