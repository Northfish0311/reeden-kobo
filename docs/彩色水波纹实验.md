# 彩字、背景图与水波纹

## 先说清楚当前状态

community.4 的 `!plan.color && !plan.frame_color` 只让黑白页进入水波纹动画，彩色页使用普通彩色刷新。它是避免彩色内容进入灰阶路径的保护，不是彩色水波纹的解决方案，也不能保证物理面板绝不淡色。

**community.5 安装包已加入独立的 CFA 彩色条带实验**，全新安装默认关闭，升级保留已有翻页模式。community.4 及更早的包不含此功能。本功能不修改官方闭源核心。软件测试只能检查像素和刷新事务，不能代替实拍，也不能证明修复了规则卡死或水波纹残影。

## 新路径做什么

- 仅用于 Clara Colour 已知的 1072×1448、rotate=3、零视口偏移画面，并且必须收到有效翻页指令。
- 含彩字、背景图或需要擦除旧彩色内容时，使用 `GLRC16 + FULL + CFA G2`；不使用灰阶 `CFA_SKIP`，不降低 RGB 饱和度，也不重新混合字色。
- 在原始整幅 RGB 图上按区域依次刷新，内部边界对齐到 48 像素，兼顾 16 像素更新对齐和 3 像素 CFA 相位；屏幕边缘裁到实际尺寸。
- 彩色最多 8 段，每段完成后才提交下一段；全程保持目标 framebuffer 不变。相比普通刷新可能更慢，也可能仍有可见接缝，需实机验证。
- 取消、提交失败或提交等待失败后，先收完已接受的事务，再回退整页普通彩色刷新；该次运行不再尝试彩色动画。完成等待失败则停止继续绘制，不假装恢复成功。
- 手动清屏、HD、主题明暗切换、硬件反相变化、过期指令、非翻页更新和未知几何仍走普通路径。从灰阶动画进入彩页时，保留原有一次完整彩色清理。
- 不在彩色动画后追加灰阶复绘，不额外设置每页全闪。以上是请求策略，不是保证面板没有闪动。

波形和模式约束参考 [KOReader 的刷新实现](https://github.com/koreader/koreader-base/blob/master/ffi/framebuffer_mxcfb.lua)及 [HWTCON 接口定义](https://github.com/koreader/koreader-base/blob/master/ffi/mxcfb_kobo_h.lua)。这里只借鉴公开接口用法；彩色分段是本项目待验证的实验，不是声称 KOReader 已替我们验证过该动画。

## 如何试用与退出实验

先使用 **community.5 OneClick 包的一键更新**完成保留数据升级，并确认正常阅读和退出。旧包不认识这个模式。正式尝试前先备份当前安装，保留可回退版本。

1. 退出 Reeden，回到 Kobo 原生系统，然后连接 USB。
2. 打开 Kobo 磁盘的 `.adds/reeden-kobo/userdata/turn-profile` 文本文件，内容改为 `color`，没有则新建同名无扩展名文件。
3. 安全弹出 USB，重新启动 Reeden；阅读器里的水波纹开关仍需打开。
4. 改回 `stable` 后重新启动，即关闭彩色实验。其他既有模式也会明确清除彩色实验参数。

开发者可在没有 `turn-profile` 覆盖时用 `REEDEN_COLOR_TURN=cfa`，配合 `REEDEN_TURN_TRACE=1` 查看刷新请求。错误的参数不会启用实验。`REEDEN_TURN_PROFILE=off` 始终优先关闭全部动画。

## 实机验收

用同一本可公开的测试书、同一字号、亮度和背景，在普通模式与 `color` 模式间对照：单个彩字、多色高亮规则、稀疏及密集背景图、白底和黑底、前后翻页、横向和纵向、彩页转黑白页。比较翻页后 1 秒的近照，不只看 framebuffer 截图。

出现彩字变淡、边界色偏、残影累积、明显变慢或卡住，就停止实验并回到 `stable`。在这些项目通过前，不能把“彩字不淡化”当作已完成的功能承诺。
