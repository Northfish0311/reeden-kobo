# 0.7.2 真机验收（2026-11-01）

设备：Kobo Clara Colour（393），固件 4.46.23836。官方核心：Reeden Kindle 1.43.2+791。

使用从 GitHub 下载的 v0.7.2 OneClick ZIP 中未修改的 `install.py`，在 macOS 上通过 USB `--upgrade` 完成安装，退出码为 0。对应源提交为 `7ce6011cb8573519cf37b9f3a8d2a853295f8d44`。

| 项目 | 结果与证据 |
|---|---|
| 安装文件读回 | 464 个清单文件 SHA-256 全部一致 |
| 阅读数据保留 | 与旧版备份比较：userdata 全部 571 文件、storage 全部 1 文件的路径和内容完全一致 |
| 原生菜单自检 | 用户重启后点击 Check，确认各项通过 |
| 设备端 verify.sh | 哈希、运行库依赖及 7 个 ARMHF 隔离测试通过；隔离显示测试不访问实体屏幕 |
| 启动 | 收到第一帧，完成硬件交接 |
| 阅读与灯光 | 用户确认阅读、翻页、前光和暖光正常 |
| 充电锁屏 | 状态 Charging，前光 0，整个 20.02 秒样本保持锁屏；触摸句柄关闭，主线程等待 poll，进程仅增加 4 个 CPU 计数 |
| 充电唤醒 | 用户确认按键恢复并可翻页；充电时正确跳过内核深睡 |
| 拔线深睡及按键唤醒 | 实际 mem 约 23 秒，返回 0；内核 success 从 1 增至 2，fail 及各失败分类为 0；同一进程恢复，用户确认可翻页 |
| 退出 | 用户确认双上角长按后返回 Kobo 主界面并可操作 |
| 诊断 SSH | 重启后密钥登录成功，仅密码认证被拒绝；密钥和专用菜单仅在测试设备，不在公开附件中 |

首次尝试采样时设备已从深睡恢复，因此未把该样本计为“充电锁屏通过”；随后在充电稳定后重新锁屏，严格检查整个窗口的锁屏状态。以上 CPU 计数用于排查空转，不是电流测量，不能换算为续航保证。

拔线测试临时配置 +30 秒 RTC 唤醒兜底，实际在兜底前按键唤醒。测试后已清除 power-test、power-alarm，确认 RTC wakealarm 为空；临时强制 Wi-Fi 设置恢复为 false，临时菜单删除。

**未覆盖**：隔夜休眠、完整电池续航、Windows 实体 USB 安装、其他机型或固件，以及本轮的无线一键安装。无线传输曾因连接不稳定中断，因此改用 USB，未将无线流程列为通过项。0.7.3 的新卸载流程另通过模拟磁盘测试，未对个人设备执行真实数据删除。以上证据不构成所有配置均正常的承诺。
