# 公开历史清理说明

0.7.1 发布时清理公开分支和版本标签所指向的历史：将最初提交中包含开发目录的预编译文件替换为相同源码的已剥离构建，并更新对应哈希；将早期说明和示例中的私人内网地址替换为文档示例地址。没有更改官方 Reeden 核心。

这会改变旧提交的标识，已有克隆不应直接把旧历史推回远端。请先导出本地未提交的修改，再重新克隆本仓库；如维护自己的分支，应从新历史重新应用改动。

本地保留原始历史备份用于恢复，不上传。分支和标签清理不能删除其他人已经下载的克隆、GitHub 缓存、旧 CI 日志或旧提交的直接链接；本次发现的是路径及内网地址，不是已确认的凭证泄露。

v0.7.0 已被替代，不用于新安装；它的历史源码仍保留历史行为和限制。请使用当前发布版本及对应安装包，不要将旧包理解为已包含这些修复。

## 2026-11-01 作者邮箱清理

经所有者明确授权，对公开 main 及受影响版本标签的作者、提交者和标签创建者邮箱改用 GitHub noreply。仅改写身份元数据及父提交/标签所引用的对象标识；历史文件树保持不变。清理前的完整历史在本地私有保留，不能上传。

旧标签因此指向新的提交标识。现存 v0.7.0–v0.7.3 Release 附件保持原发布字节：其中 COMMIT.txt、ZIP 注释和旧验收记录可能仍记载清理前的标识，不能当作清理后的标签 ID。历史 Release 已加说明；新 v0.7.4 由清理后的标签 CI 生成，附件与新提交重新一致。

原提交的直接链接、服务端缓存、Actions 记录和别人已有的克隆不一定消失；改写不能保证从互联网抹去曾公开的身份信息。请重新克隆或在备份本地修改后重新同步，不要把旧历史推回公开分支。
