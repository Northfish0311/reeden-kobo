# Debian 运行库的安全维护评估

评估日期：2026-11-01。此文区分已经实施的校验与尚未完成的迁移，不表示依赖已无漏洞。

## 当前事实

- `vendor/debian-runtime-manifest.json` 固定 10 个 Bullseye 包的版本、下载 URL 与 SHA-256，其中包括 GLib 2.66.8、libffi7、PCRE/PCRE2、util-linux 库、zlib、libselinux、libgcc 和 ca-certificates。
- 官方 Kindle 1.43.2+791 随包私有 glibc 的实测版本字符串为 **Debian GLIBC 2.31-13+deb11u14**；它来自官方包，不在本项目 10 包清单中。迁移不能只更新一份 JSON 后假定 loader 与所有库仍兼容。
- 固定版本及哈希用于来源完整性、复现和缓存校验，不会自动获得安全补丁，也不等于 CVE 扫描或发行版安全签名验证。
- Debian 官方列明 Bullseye 免费 LTS 于 **2026-08-31** 结束，目前已经结束。[Debian Bullseye 生命周期](https://www.debian.org/releases/bullseye/)。
- Debian 官方列明 Bookworm LTS 支持 armhf，计划至 **2028-06-30**。这是可评估的迁移候选，不能据此保证本设备和官方引擎可运行。[Debian Bookworm 生命周期](https://www.debian.org/releases/bookworm/)。

## 选项与决定

| 路线 | 收益 | 代价与限制 | 当前决定 |
|---|---|---|---|
| 原样冻结 Bullseye | 保持当前已验证 ABI 与可复现行为 | 免费 LTS 已结束；固定的旧包也不会自动跟随最后补丁 | 仅保留为当前兼容基线，明确披露；不称为长期安全方案 |
| 更新至可取得的最后 Bullseye 修订 | 可纳入已经发布的修复，ABI 变化通常较小但仍需测 | 不能解决 EOL 后的持续维护，需重新核验版本/哈希/依赖 | 可作为迁移前的过渡评估，尚未更改清单 |
| Bookworm armhf 私有运行时 | 有明确的 armhf LTS 窗口 | GLib/libffi SONAME、GLIBC 符号版本及 loader 需成套检查；设备内核和闭源引擎必须验证 | 优先进行分支验证；未完成前不替换发布包 |
| Freexian ELTS | 可能延续 Bullseye 补丁来源 | 商业支持仅覆盖约定的软件包与架构，需确认 armhf 和实际清单；项目未订阅 | 备选，无资金或覆盖范围承诺 |

[Freexian ELTS](https://www.freexian.com/lts/extended/) 说明支持的软件包与架构有限，不能把“有 ELTS”写成当前项目已被支持。

## 后续迁移的发布门槛

1. 从官方 Debian 元数据核对新包版本、架构、来源包、完整依赖和 SHA-256；核查对应 Security Tracker/DSA/DLA，不以“版本更新”替代已知漏洞分析。若旧 URL 消失，应明确失败，不能退到未经校验的镜像。
2. 生成候选包清单，检查所有 `DT_NEEDED`、SONAME、GLIBC/GLIBCXX 符号版本和实际 loader；保持运行库私有，不覆盖 Kobo 系统库。更新 libc/loader 时也需核对官方核心使用方式，不能混用不一致的组件。
3. ARMHF 隔离、QEMU 和目标 loader 检查通过后，在 Clara Colour 393 上重测：首帧、书籍/数据库、导入、HTTPS、字体、彩色/黑底刷新、前光暖光、锁屏深睡/唤醒、退出及升级回滚。
4. 新标签、新附件、新哈希发布；记录实际变更、风险和回退路径。旧安装保留数据备份，不能静默换掉旧 Release 文件。
5. 每次发布重新核对依赖状态，发生新的高风险问题时决定补丁、停止推荐或暂停相关功能。尚未设置定时扫描、签订 ELTS 或承诺固定更新频率。

## 本轮边界

本轮修复安装器的解包路径与链接边界，补充依赖风险说明；**没有升级 Bullseye 库、官方 glibc、闭源引擎或 Kobo 内核**，也没有完成逐项 CVE 可利用性审计。后续 ABI 和真机迁移属于独立工作，不能将这份方案视为迁移已完成。
