# 普通 / 原版 / 实验动画 A/B 测试流程

本文件是后续实机验收的准备，不表示已经安装或执行。当前实体设备和原开发目录保持不变。**实验默认关闭，尚不能宣称视觉效果或速度提升。**

## 构建与产物

先在本独立工作树运行 `scripts/test-turn-offline.sh`，再设置已有 Zig 0.13.0 路径运行 `scripts/build.sh`。本次已完成这些步骤，以及 headless 编译。

实验宿主位于 `package/bin/reeden-kindle`；检查程序位于 `build/*-test-armhf`。`prebuilt/` 仍保留基线产物：直接运行本树原来的 `install.py` 不会自动把实验宿主装进去，不能把它当成已完成实验安装。

审计目录另准备了带 SHA-256 的本地 adapter-only overlay，供审阅与未来组包使用；它没有官方核心、运行库、字体和用户数据，也不是可直接运行的一键安装包。部署时必须与完整安装清单一并处理，不能只替换一个二进制绕过校验。

后续只有在用户另行同意实体试验后，才先退出 Reeden、备份当前完整程序及清单，组出校验一致的实验包并部署。保留原 userdata/storage、现有密钥 SSH 和当前稳定版回滚点。本轮没有执行这些设备步骤。

## 三组可比设置

所有组使用相同官方核心、同一份书籍、字号/行距、灯光、主题、全刷间隔。普通翻页动画设为“无动画”，水波纹功能保持开启，使三组收到相同的语义 arm 指令。下列命令仅供之后在**已获同意并正确部署实验宿主**的设备上手动运行，本轮未执行。每次先正常退出，回原生系统再启动下一组。

```sh
APP=/mnt/onboard/.adds/reeden-kobo

# A：普通刷新；保留相同的前端设置和其他后端策略
REEDEN_TURN_PROFILE=off REEDEN_TURN_TRACE=1 "$APP/run.sh"

# B：原开发版算法；前端水波纹速度选当前已接受的“快”
REEDEN_TURN_PROFILE=stable REEDEN_TURN_TRACE=1 "$APP/run.sh"

# C：空间比例时序；先用同样的 16 段，不先增加次数
REEDEN_TURN_PROFILE=timed REEDEN_TURN_TRACE=1 \
REEDEN_TURN_BANDS=16 REEDEN_TURN_SPAN_US=150000 \
REEDEN_TURN_MIN_GAP_US=2000 REEDEN_TURN_MAX_INFLIGHT=0 "$APP/run.sh"
```

各轮退出后，把 `logs/current.log` **只读下载到电脑**，分别存成 `A-off.log`、`B-stable.log`、`C-timed.log`。日志会在下一次启动时更新，必须先保存。每次只传本轮列出的环境变量，不残留上一轮参数。

从电脑执行分析，显式注明真实设备来源：

```sh
python3 scripts/analyze-turn-trace.py A-off.log --evidence device --output A-off.json
python3 scripts/analyze-turn-trace.py B-stable.log --evidence device --output B-stable.json
python3 scripts/analyze-turn-trace.py C-timed.log --evidence device --output C-timed.json
```

自动分析会记录 profile/参数、每次 send/submission wait/completion wait、区域、wave、flags、返回值、marker、在途峰值、间隔最小/最大/标准差、分阶段时长。普通组的 `requested_bands=0` 表示该参数不适用，不表示没有刷新。

trace 会增加日志输出开销；正式视觉比较再将 `REEDEN_TURN_TRACE=0` 各测一遍。不能把开日志与不开日志的两组混在一起声称提速。所有光学效果仍以实拍/现场反馈为准。

## 单变量参数矩阵

| 对比 | 改什么 | 保持什么 | 目的 |
|---|---|---|---|
| C12 / C16 / C24 | 段数 12/16/24 | span=150000、min_gap=2000、window=0、原波形 | 比较条带宽度；不把更多段数和更慢周期绑在一起 |
| T100 / T150 / T200 | span=100000/150000/200000us | 16 段，其余相同 | 找到可见扫动与响应的折中 |
| Q0 / Q4 / Q8 | max_inflight=0/4/8 | 选定段数与周期 | 判断队列压力；上限更小可能反而更慢，不默认启用 |

参数边界：bands 4～32；span 40000～350000us；min_gap 1000～20000us；max_inflight 0～8，0 表示不额外限制。最小间隔乘以段间数量若已经超过总周期，配置被拒绝并回到 stable。`max_inflight=1` 允许诊断串行完成，但通常会产生明显分段和较大延迟，不作为推荐设置。

timed 保留已验证的日8/夜9 + CFA_SKIP；本轮不把 DU/A2 二值化或额外全刷当作提速。未知几何、彩色、旧色擦除、显式清屏等场景走安全普通路径。

## 测试内容与停止条件

每组先使用可公开的同一本黑白测试书及相同页码。开始前用相同方式清理一次面板状态；随后保持全刷频率一致。实际自动全刷和彩页回退要单独标记，不能为了平均数好看而隐去。

1. 白底灰阶前翻 10 次、后翻 10 次。分别观察开始方向、竖线、整高条带、速度、末尾停顿、文字边缘。
2. 同页重复并随机交换 A/B/C 顺序，至少两轮；不要每组使用不同难度的页面。
3. 连续快速翻页及反向操作，记录最终页码是否符合输入次数、是否积压、是否出现半页或重复旧页。离线重复 arm 测试不替代这一项。
4. 夜间灰阶；夜间带单个彩字；密集彩字；图片；旧色擦除；跨章节；阅读菜单开关。预期不满足动画条件时回退正常，不能强行扫动彩色内容。
5. 在扫动过程中短按电源键，然后唤醒；验证没有花屏、卡死或阅读位置错误。当前主线程仍同步，电源键可能等本轮返回后才处理；不能宣传即时中断。
6. 合作式取消 API 的前几段、中间段、末尾段先做受控测试。当前没有 UI 取消按钮；未来若做实际中途退出，需要单独安排有回滚保护的诊断，不把动画结束后的普通退出算作“途中取消已实测”。
7. 测试退出回原生系统、Wi-Fi 交接、前光暖光和重开书籍；不改变已有的休眠、电源和无线策略。

出现请求/完成 ioctl 错误、未清除的在途任务、半页、色彩异常、无法退出或唤醒异常，立即停止该候选；保留日志，回到稳定版本。不要继续调快参数掩盖错误。

## 视频与人工验收

需要提供同一页面 A/B/C 的实拍慢动作视频，优先 120/240fps；没有慢动作时提供现场逐项反馈。固定机位和曝光，保持灯光、前光和色温一致，尽量让手指触屏动作与整个屏幕同时入镜。使用愿意分享的内容，避开私人书名、笔记和账号。

需要比较的可见指标：触屏到首次墨水变化、首次变化到最后稳定、推进前缘宽度、是否有停顿或直线边界、闪烁面积与亮度、最终文字清晰度、翻多页后的残影。软件 `complete_ns` 不等于光学稳定；framebuffer 截图也不包含面板残影，不能替代实拍。

分析工具的 input 时间是 evdev read 返回时间，不包含此前在输入队列里的积压；render 时间是关联 Flutter 回调到达时间，不是官方引擎内部绘制开始。缺失字段输出 null，不能按 0ms 计算。任何设备请求是否真正合并的结论，还需要驱动可用的任务诊断或与视频对应的证据。

验收标准是自然度、响应、字形和残影均可接受且稳定性不退化。未拍摄/未反馈时，只能报告“离线验证通过，实体效果未测”。

## 在设备上切换（不需要 SSH）

把下面任意一个词写进 `/mnt/onboard/.adds/reeden-kobo/userdata/turn-profile`，退出 Reeden 后从 NickelMenu 重新启动即可。该文件放在 `userdata/` 下，重装或升级会保留；文件不存在时使用默认值。

| 文件内容 | 效果 | 对应上表 |
| --- | --- | --- |
| `stable` 或留空 | 默认动画（当前有下缘残影） | S |
| `reagl` | 补偿分段：分段、速度不变，白底改用 raw 4 / FULL | R |
| `clean` | 动画结束后追加整页复绘，仅供诊断；历史实测反馈闪烁或变慢，不建议日常开启 | Q |
| `off` | 完全不使用水波纹动画 | N |
| `timed` | 实验用定时分段，未证明更省电或更干净 | T |

切换前先退出 Reeden，不要同时运行两个宿主。用 USB 改文件后安全弹出，再启动阅读器；不需要改系统配置。想看某一档是否干净，建议先只改这一个文件、其余设置不动，翻同一本书的同一页对比。没有证据表明这些模式能修复规则卡死。

## 回退

- 当前没有设备改动：原机器和原 main 直接继续使用即可。
- 实验宿主未来已部署时，去掉 `REEDEN_TURN_*` 参数即回到 stable 算法；环境参数不写入原阅读设置。
- 需要字节级回退时，退出 Reeden 后恢复部署前一起保存的宿主、检查程序、build-info、SHA256SUMS，完整校验后重开；保留 userdata/storage。
- 本地基线分支是 `local/animation-baseline-20261102`；实验分支独立存在。不要用 `git reset --hard` 清理原目录，那里保留着用户原来的未提交工作。
