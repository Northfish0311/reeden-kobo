# Reeden Kobo 0.7.1 — Experimental

> 此版本已被 v0.7.2 替代。0.7.1 将自检菜单超时设为 60 秒，不符合 NickelMenu 小于 10 秒的要求；请使用 v0.7.2。以下保留原发布记录。

适用于 Kobo Clara Colour（产品代码 393），已测固件 4.46.23836。官方核心白名单仍为 **1.43.2+791 / 1.43.1+780**；不包含官方闭源核心，官方包需自行取得。电脑安装器要求 **Python 3.10+**。

## 修复

- 锁屏关闭触摸设备时立即使句柄失效；锁屏期间不轮询触摸设备，输入句柄出错则返回原生界面。修复可导致锁屏期间空转耗电的代码路径，实际续航改善尚需设备测量。
- USB 和 SSH 升级在旧安装仍完整保留时准备新版与阅读数据；替换目录或菜单失败时尝试恢复原安装，并保留失败恢复所需的路径信息。备份仍占用空间，写入时不可拔线，断电不保证自动恢复。
- 屏幕自检重新校验当前文件，不再把旧日志或成功标记当成当前校验通过。菜单允许最多 60 秒完成自检。
- 默认不提供启动 SSH 的菜单；可选诊断脚本仅允许密钥认证，增加 start/stop/status。升级不会自动终止已运行的旧 SSH，**请点击 Reeden SSH - Stop 并结束已有会话，或重启设备**。
- 每次启动额外核验产品代码；澄清硬件恢复能力、DNS 写入和可选 SSH 依赖，移除绝对安全承诺。
- 清理公开分支/标签历史中的开发目录与私人内网示例地址；已有克隆请按仓库的历史清理说明重新同步。其他人的下载副本和服务端缓存不在此清理范围内。
- 发布产物统一由标签 CI 生成，附 `COMMIT.txt`、`SHA256SUMS`；不再在旧标签下替换不同代码的附件。

## 下载和升级

下载本页 `Reeden-Kobo-Adapter-v0.7.1-OneClick.zip`，解压后按 README 安装。已有用户先退出 Reeden，使用 `--upgrade` 保留书库与阅读记录。请预留新版及阅读数据副本所需空间。

校验安装附件 SHA-256 见同页 `SHA256SUMS`；`COMMIT.txt` 指明精确源提交。两个 ZIP 及 GitHub 自动生成的源码均对应同一标签提交。

## 验证范围

本版本 CI 覆盖 Python 3.10/3.12 安装与恢复回归、Linux C 回归、ARMHF 重编译与预编译逐字节一致性，以及 QEMU 下的 ARMHF 输入和显示隔离测试。新增空间不足、复制失败、目录替换失败、菜单替换失败、当前文件校验失败、密钥认证参数和触摸句柄复用测试。

0.7.0 的既有实体体验不能替代 0.7.1 验收。本版发布时仍需复测：充电锁屏 CPU/电流、隔夜休眠与唤醒、真实 SSH 密钥登录、彩色内容与黑底灰阶切换。未声称所有配置均已验证，也没有把已有耗电问题归为单一原因。保护盖休眠和自动空闲休眠尚未实现。
