# Reeden Kobo 0.7.5 — Experimental / 翻页动画与夜间彩字刷新

仅支持 **Kobo Clara Colour（393）/ 固件 4.46.23836**，电脑需 **Python 3.10+**，设备需已安装 NickelMenu。下载 `Reeden-Kobo-Adapter-v0.7.5-OneClick.zip`，完整解压后运行三平台一键安装脚本；已有安装先退出 Reeden，再使用 `--upgrade` 保留数据升级。官方核心白名单仍为 Kindle 1.43.2+791 / 1.43.1+780，由用户提供或安装器从官网获取并校验，不随附件分发。

## 本版更新

- 接入官方“水波纹翻页”设置，在 Kobo 上实现分条扫动，支持方向、纵向和速度档位。建议先选快档，并将普通“翻页动画”设为“无动画”。这是 Kobo 分区模拟，不是 Kindle 私有硬件接口的原样移植；彩色页面、锁屏和清屏仍走普通刷新路径。
- 夜间稀疏彩字按旧、新彩色区域分组刷新，减少 CFA 彩色刷新覆盖；保留密集彩字、图片、主题切换及主动清屏的完整刷新路径。
- 整合 Wi-Fi 状态/控制桥接、原生会话网络交接及带时限的恢复命令，并补齐网络回归测试。
- 加入翻页时序日志、离线分析、可选像素证据及文字质量实验。实验选项仍默认关闭；Q（动画后整页复绘）因闪烁或变慢的用户反馈已撤回，保持关闭。继承 v0.7.4 安装器归档安全修复。

## 实机记录与用户反馈

- 2026-11-02：快档白底灰阶页 8 次前翻、2 次后翻均完成，用户确认“更连续了，效果和速度可以接受”。条带提交跨度约 147～179 ms，不是完整翻页耗时。普通/慢档及夜间动画没有本轮独立实体效果验收。
- 夜间彩字当前书页对照：用户确认“闪烁缩小，文字和颜色正常”；不代表所有书籍、图片和密集彩字都已验收。
- 文字质量实验 R 的设备反馈为横影减轻、扫动和速度正常，但仍有很淡的文字残影。**残影尚未完全消除**；该实验反馈不能作为默认安装效果承诺。Q 不满足体验验收，未作为默认修复发布。
- 2026-11-03 用户实际使用反馈：**隔夜休眠问题已解决，续航实测可接受**。本次发布未新增设备测试或功耗测量，也没有对其他机型、固件或官方核心进行全面实机复测。

## 自动化验证边界

本标签使用现有 CI & Release 工作流：Python 3.10/3.12 回归，Linux/macOS/Windows 模拟 USB 安装与卸载，Zig 0.13.0 ARMHF 重编译与全部预编译件逐字节比较，Linux C 回归，以及 QEMU ARMHF 合成输入/显示测试。发布任务仅在这些检查全部成功后生成附件。合成测试、mock ioctl、QEMU 和编译通过不能代替实体屏幕效果、光学稳定时间、隔夜休眠或真实功耗测量。

完整记录见[刷新与翻页动画开发记录](../刷新与翻页动画开发记录.md)、[文字下缘横向拖影诊断](../文字下缘横向拖影诊断-20261102.md)及[历史验收与测试边界](../测试说明.md)。
