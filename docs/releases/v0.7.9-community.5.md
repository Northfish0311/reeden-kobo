# Reeden Kobo v0.7.9-community.5（社区实验版）

面向 **Kobo Clara Colour（产品代码 393）**。基于 SSNQ v0.7.8 与本仓库 community.4，保留原作者署名和许可证，不包含或修改 Reeden 官方闭源核心。

**这次更新安装包，但不宣称已经解决隔夜耗电、彩字淡化、水波纹残影或规则卡死。** 彩色水波纹实验默认关闭；自动测试不能代替真实墨水屏和功耗验收。

## 下载哪个文件

普通用户只需下载 **Reeden-Kobo-Adapter-v0.7.9-community.5-OneClick.zip**，完整解压到新文件夹。电脑需 Python 3.10+，Kobo 需已有 NickelMenu。

| 附件 | 用途 |
| --- | --- |
| `Reeden-Kobo-Adapter-v0.7.9-community.5-OneClick.zip` | 普通用户的一键安装、保留数据更新与卸载工具 |
| `Reeden-Kobo-v0.7.9-community.5-Source.zip` | 开发者查看同一版本源码；普通用户不必另外下载 |
| `COMMIT.txt`、`SHA256SUMS` | 源提交与附件校验值，不是安装程序 |
| GitHub 自动生成的 `Source code` | 源码归档；普通用户仍选上面的 OneClick 包 |

官方 Kindle 核心仍由安装器按原白名单单独校验和组装，许可及版本限制不变。不需要自己编译 C 程序。

## 已经安装，怎样更新

1. 先备份重要书库和笔记。退出 Kobo 上的 Reeden，回到原生主页。
2. 接 USB，在 Kobo 上点“连接”。
3. 解压新版 OneClick 包。Windows 双击 **一键更新-Windows.bat**；Mac 双击 **一键更新-macOS.command**；Linux 运行 `sh 一键更新-Linux.sh`。
4. 等待提示完成，再安全弹出 USB。更新会保留书库、笔记、阅读进度、已有翻页模式，并备份旧安装；不要写入中拔线。
5. 先验证正常启动、阅读、退出和锁屏。首次安装的用户使用同目录“一键安装”。

更新入口安装当前下载包里的版本，不会自动换成未来版本。不要把新旧文件夹混在一起，也不要只覆盖一个程序文件绕过校验。详细见[安装与卸载说明](https://github.com/Northfish0311/reeden-kobo/blob/v0.7.9-community.5/docs/安装与卸载.md)。

## 这次改了什么

- **保护盖初始状态：** 启动时记录盖子现状，不将“本来已经合盖”误当成刚发生的合盖事件；后续真实开合仍会触发处理。
- **锁屏图片失败处理：** 可选封面图片不可用时保留当前画面，继续锁屏与休眠流程，不再主动亮屏返回阅读；显示完成状态不明时仍停止绘制并走错误恢复。
- **彩色水波纹实验：** 新增独立的 CFA 彩色条带路径。彩字、彩色高亮和背景图保留原始 RGB，不进入灰阶扫动；最多 8 段，逐段完成后继续。失败时回退普通彩色刷新，本次运行关闭彩色实验。
- **只读验收工具：** 检查合盖、启动、无线、翻页和休眠日志，区分“找到证据、明确失败、证据不足”。补充识别彩色条带日志；不会修改 Kobo，也不会自动把截图或日志上传到网上。
- **发布和说明同步：** 安装器版本、预编译适配层、校验表、中文说明与本标签保持一致。Windows 只读验收工具的合成回归纳入发布门禁。

## 彩色水波纹怎样试

**普通阅读不用开启。** 首次安装默认关闭，已有的 `userdata/turn-profile` 在升级时保留。

完成本版更新并确认普通阅读正常后，退出 Reeden、连接 USB，把 Kobo 磁盘中 `.adds/reeden-kobo/userdata/turn-profile` 这个无扩展名文本文件的内容改为 `color`。安全弹出后重开 Reeden，阅读器内仍需开启水波纹。改回 `stable` 后重开即可关闭彩色实验；`off` 则关闭全部水波纹。

彩色分段可能更慢，也可能有接缝或色偏。先用同一页对照，出现不适立即退回普通模式。没有保证彩字绝不淡化，也没有保证高亮规则不会卡死。详细见[彩色水波纹实验说明](https://github.com/Northfish0311/reeden-kobo/blob/v0.7.9-community.5/docs/彩色水波纹实验.md)。

## 验证边界

发布必须通过三平台双 Python 版本的模拟 USB 检查、Python 回归、Linux C 测试、ARMHF 重建与预编译件逐字节比较、QEMU 显示/输入测试、Shell 检查和 Windows 只读验收工具的合成回归。发行 ZIP 在 GitHub 上检查内容一致性和校验值后上传；以本标签 Actions 结果为准。

**本版未完成真实 Kobo 安装、合盖唤醒、隔夜功耗和彩色屏幕效果验收。** 固件 4.46.23836 的上游历史实测不等于本版或 4.46.23852 已通过。当前电源键输入仍按既有路径处理，新增的输入枚举工具只是诊断，不宣称已经自动适配任意固件。

设备控制面板和 Wi-Fi 开关沿用 community.4；退出回原生后沿用无线选择仍需要已有 NickelDBus，缺少时不能保证同步。USB 充电时只锁屏，不强制深睡；“调用休眠脚本”或 `mem` 成功返回都不等于测得最低功耗。

合盖行为异常时，先使用电源键；退出 Reeden、接 USB 后，在 `.adds/reeden-kobo/userdata/` 创建空文件 `no-sleep-cover`，下次启动停用盖检测。回退时优先使用更新前保留的完整备份，保留阅读数据，不手工混搭程序与校验清单。
