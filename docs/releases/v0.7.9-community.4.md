# Reeden Kobo v0.7.9-community.4（社区实验版）

基于 SSNQ v0.7.8 和本仓库 community.3，面向 Kobo Clara Colour（393）。保留原作者署名及许可证，不包含或修改官方闭源核心。本版不宣称解决隔夜耗电、水波纹残影或规则卡死。

## 普通用户怎么更新

1. 下载本页 **Reeden-Kobo-Adapter-v0.7.9-community.4-OneClick.zip**，完整解压到新文件夹。
2. 先退出 Kobo 上的 Reeden，回到原生主页，再接 USB 并点“连接”。电脑需 Python 3.10+，Kobo 需已有 NickelMenu。
3. Windows 双击 **一键更新-Windows.bat**；Mac 双击 **一键更新-macOS.command**。保留书库、笔记、进度并备份旧安装，不需要重置机器。没有安装过的用户用同目录的“一键安装”。
4. 等待电脑提示完成，再安全弹出 USB。先验证正常启动、短按电源键锁屏/唤醒及退出回主页，再按下面的步骤使用新增功能。

`Source.zip` 面向开发者；`COMMIT.txt` 标明源提交，`SHA256SUMS` 校验下载文件。普通用户只需 OneClick ZIP。更新入口安装当前下载包，不会自动换成将来版本。

## 新功能怎么用

1. **设备控制：** 在 Reeden 内，从屏幕顶部中间向下滑，打开中文控制面板。点“返回阅读”或右上角关闭按钮回到原页面。
2. **Wi-Fi：** 点击开关，实际开启或关闭 Kobo 无线接口。开启后复用原生系统已保存的网络，不显示或记录密码。状态分“已关闭”“已开启，未连接”“已连接”；点右上角“刷新”再次核对。首次连接新热点仍在原生系统完成。
3. **合盖：** 保持 Reeden 打开，合上磁吸保护盖，适配层会锁屏、关前光并在条件允许时尝试内核休眠；开盖请求恢复。没有保护盖时用“立即锁屏”或电源键。面板显示“传感器暂不支持”时请用电源键。
4. **与原生系统交接：** 运行中的开关就是 Kobo 的真实无线状态，不是模拟开关。退出回原生后继续沿用这个选择需要已有 [NickelDBus](https://github.com/shermp/NickelDBus)；缺少时会记为未同步，原生系统保留自己的控制策略。不会自动安装插件，更不会承诺所有固件无条件同步。具体接口来自 [NickelDBus 文档](https://shermp.github.io/NickelDBus/ndb-ndbdbus.html)。

## 这次修改

- **新增设备控制面板。** 由开源适配层绘制中文开关和状态，不修改闭源核心。异步执行无线命令，处理中阻止重复点击；退出面板恢复最新阅读画面，不把旧截图盖回页面。只在操作时查询，不增加常驻无线轮询。
- **新增保护盖监听，识别后默认启用。** 独立识别内部 `SW_LID` 或已知 Kobo GPIO 的 `KEY_F1`，排除 USB/蓝牙键盘，不抢占额外输入设备。对边沿去抖、重复事件和输入缓冲溢出重同步；未知传感器不猜测。合盖/开盖直接接到锁屏/恢复流程，不要求先退出软件。
- **休眠保护。** 供电状态不明确、正在充电或显示仍忙时不强制休眠；进入内核休眠前再次检查供电和取消标记。
- **异常短暂返回不直接亮屏。** 休眠请求短时间返回或显示暂忙时，每次锁屏最多延迟 8 秒重试一次，用户唤醒优先。盖子仍关着时延后 Wi-Fi 恢复；不添加无限重试、常驻轮询服务或日常 RTC 唤醒闹钟。
- **正常退出与故障恢复分开。** 用户明确调整的亮度、色温暂存在 RAM；只有确认正常退出才交接，异常时恢复启动快照，不把临时灭灯当成偏好。正常退出且用户选择了非零亮度时同步原生亮度配置，色温不写原生配置。成功的 Wi-Fi 主动开关另存本次会话记录，休眠断网不覆盖它，异常退出也不会误用另一会话的旧选择。
- **原生 Wi-Fi 由原生系统管理。** 保留默认断电交接和可选 `wifi-handoff=keep`。已有 NickelDBus 时有限等待其启动，请求用户选择并核对真实接口；缺少入口、调用失败或状态不符时记录“未同步”，不擅自安装服务或在 Nickel 下重新启动自己的网络进程。“接口已开启”不等于已连热点或能访问互联网。
- **只读待机报告。** 连接电脑后可在解压目录运行 `python -B scripts/standby_report.py`，只总结现有日志的合盖事件、供电状态、电量与休眠阶段。不上传数据、不写 Kobo、不采样整夜。
- **保留 community.3 改动。** 启动校验缓存、缺失资源修复、首帧保护、彩色页刷新及 USB 保留数据更新继续保留；README 与下载链接同步到本版。

## 验证与限制

发布流程要求 Windows、macOS 15、Linux 的 Python 3.10/3.12 模拟 USB 检查、Linux 脚本故障注入、C 回归、ARMHF 重新构建与预编译件逐字节一致、QEMU 合成输入/显示测试全部通过。没有用“忽略失败”放行 macOS 检查。请以本标签的 Actions 结果为准。

**尚未完成本版的真实 Kobo 安装、合盖休眠、开盖唤醒、隔夜功耗和原生设置交接验收。** `mem` 返回成功或前后相隔数小时，不等于测得真正低功耗。曾只读识别到一台 393 / 固件 4.42.23291；这不是该固件兼容认证。上游其他固件上的历史实测也不能替代本版验收。

彩色文字和背景图的自动检查仅证明合成帧像素没有被适配层改成灰色，不代表物理墨水屏颜色、残影或闭源规则引擎已验证。原有水波纹问题仍需实机对照。

**关闭实验性合盖检测：** 若保护盖行为异常，先用电源键；退出 Reeden、接 USB 后，在 `.adds/reeden-kobo/userdata/` 创建空文件 `no-sleep-cover`，下次启动会停用盖检测。删除它恢复默认。不修改内核唤醒参数，也不要用反复断电代替排错。备份、原始日志和阅读数据勿公开上传。
