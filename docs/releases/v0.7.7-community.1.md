# Reeden Kobo v0.7.7-community.1（社区实验版）

原作者：[SSNQ/reeden-kobo v0.7.7](https://github.com/SSNQ/reeden-kobo/releases/tag/v0.7.7)。这是 Northfish0311 的社区修复包，不是 Reeden、Kobo 或 SSNQ 的官方发布。

## 下载和更新

1. 下载 **Reeden-Kobo-Adapter-v0.7.7-community.1-OneClick.zip** 并完整解压。其他 Source ZIP 面向开发者，SHA256SUMS 用于校验下载，不用双击。若自己准备了官方核心，请保留原始 `Reeden-kindle.zip`，不要解压它。
2. 电脑需 Python 3.10+，设备需为已安装 NickelMenu 的 Kobo Clara Colour（393）。先备份重要书籍和笔记，退出 Kobo 上正在运行的 Reeden，用 USB 连接电脑，在设备上点「连接」。
3. 已装过 Reeden：**MacBook Air / Mac** 双击 `一键更新-macOS.command`，**Windows** 双击 `一键更新-Windows.bat`，Linux 运行 `sh 一键更新-Linux.sh`。首次安装请选择对应的「一键安装」。更新完成后安全弹出 Kobo。

## 修复

- 避免上次异常中断遗留的恢复标记阻塞启动；正在工作的恢复进程不会被抢占。
- 充电仅锁屏时继续监测阅读器；真正深睡仍获豁免。屏幕未确认锁屏封面时取消这次休眠。
- 返回 Kobo 主页时 Wi-Fi 交还失败会留下提示并在下次安全交接时重试，不会在原生界面下擅自重置无线。
- 安装确认框输入「取消」不写设备。已修改或无法读取的菜单会保留，新默认模板保存在应用目录。原始 Kindle ZIP 仍按上游白名单严格校验。

已通过[整合版自动化检查](https://github.com/Northfish0311/reeden-kobo/actions/runs/42014699108)：Windows、macOS、Linux 的 Python 3.10/3.12 模拟 USB 安装、更新与卸载，Linux 故障注入，ARMHF 重新构建逐字节验证，以及 QEMU 输入与显示测试。本次没有实体 Kobo 验收，不能据此推断续航、残影或其他型号兼容性。未附带 Reeden 闭源核心。[安装器提案](https://github.com/SSNQ/reeden-kobo/pull/1)和[阅读器提案](https://github.com/SSNQ/reeden-kobo/pull/2)分别提交给原作者审核。
