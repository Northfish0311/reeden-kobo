# Reeden Kobo 0.7.3 — Experimental

仅支持 Kobo Clara Colour（393），已测固件 4.46.23836。电脑要求 Python 3.10+，设备需已安装 NickelMenu。官方核心白名单仍为 Kindle 1.43.2+791 / 1.43.1+780。

## 下载

下载本页 `Reeden-Kobo-Adapter-v0.7.3-OneClick.zip`，完整解压后双击对应系统的「一键安装」或「一键卸载」。USB 安装不需要 SSH、KOReader 或编译器；官方闭源核心仍由用户自行提供或安装器从官网获取并校验。已有安装先退出，再按交互提示升级，或使用 `python3 install.py --usb --upgrade`。

## 本版更新

- 新增电脑端 USB 一键卸载：macOS / Windows 双击脚本及 Linux 启动脚本，免 SSH、免联网。
- 默认将整个应用改名备份并移除未自定义的标准菜单；保留书籍、笔记、进度、设置及诊断配置，备份仍占空间。
- 可选择删除当前安装及其中阅读数据，需要输入 `DELETE REEDEN`；历史备份与自定义菜单保留并提示处理。
- 错误机型、活跃会话锁及符号链接路径拒绝卸载；菜单移除失败尝试回滚；删除中断报告剩余目录。
- 安装/卸载检测到多个 USB Kobo 时停止，要求明确指定设备，防止默认操作第一台。
- 修正 Windows 启动脚本的退出码传递；安装、升级、卸载、备份恢复说明统一补齐。
- 公开补充 v0.7.2 的真机验收记录及密钥 SSH 结果。阅读引擎、刷新、灯光和电源行为延续 0.7.2，本版仅更新工具、文档及版本标识。

## 验证与限制

新增卸载测试覆盖完整备份、当前安装定界删除、重复卸载、错误设备/活跃会话拒绝、自定义菜单保留、菜单删除失败回滚、删除失败保留位置、无确认拒绝删除及多设备不误选。CI 在 macOS / Windows / Linux、Python 3.10 / 3.12 运行模拟 USB 安装和卸载；原有 Linux 回归、ARMHF 可复现构建及 QEMU 检查继续执行，发布依赖全部通过。

v0.7.2 已完成一台真实 Clara Colour 的 macOS USB 保留数据升级、阅读灯光、充电锁屏 CPU、短时拔线深睡/按键唤醒与退出验收。新卸载流程的通过依据是模拟 USB 盘测试，未在个人设备上执行彻底删除；不将自动化视为真实设备数据删除验收。隔夜休眠、实际电池续航、其他固件及 Windows 实体安装尚未验证。

如果启用过 Reeden SSH，请先退出并重启设备，再连接 USB 卸载；电脑端卸载不能关闭仍在设备内存中的 SSH 进程或会话。默认备份中可能含私人书籍、笔记和密钥，勿公开分享。删除当前安装不清理以前备份，断电和拔线也不能保证自动恢复。

使用指南：[安装与卸载](https://github.com/SSNQ/reeden-kobo/blob/v0.7.3/docs/安装与卸载.md)；真机记录：[0.7.2 验收](https://github.com/SSNQ/reeden-kobo/blob/v0.7.3/docs/真机验收-0.7.2.md)。
