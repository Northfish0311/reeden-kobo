# Reeden Kobo v0.7.7 (Experimental)

在已发布的 [v0.7.6](https://github.com/SSNQ/reeden-kobo/releases/tag/v0.7.6) 基础上，补齐旧版官方核心校验与设备卸载错误处理。v0.7.6 保留不变。

- 官方 Kindle 1.43.1+780 核心除原两库 SHA-256 白名单及版本资源检查外，要求许可证、glibc 启动程序与 libc 存在且非空；字体清单必须为数组，各条目、字体列表与资源路径类型必须有效，引用字体必须存在且非空。畸形输入以校验失败报告。
- 设备端卸载区分菜单内容不同与 `cmp` 执行错误。比较出错时保留菜单入口，报告已保存的程序及阅读数据位置并返回失败，避免误报卸载成功。
- 安装器、组包元数据、下载标识与当前文档递增至 0.7.7。

沿用 v0.7.6 的下载重试、原子缓存替换、逐候选校验、强制下载语义和 791 全文件 SHA-256 清单。780 未取得官方历史完整包，仅以合成兼容性回归验证；新增必需文件与结构检查不代表其余文件的来源或完整性认证。

支持范围仍为 Kobo Libra Colour（393）/ 固件 4.46.23836，电脑需 Python 3.10+，设备需 NickelMenu。翻页动画、淡残影和实验功能边界沿用 v0.7.5，本次没有新增真机验收。

安装：完整解压 `Reeden-Kobo-Adapter-v0.7.7-OneClick.zip`，运行对应平台脚本；已有安装先退出 Reeden，使用 `--upgrade` 保留数据升级。官方核心不随本项目附件分发。

发行附件：

- `Reeden-Kobo-Adapter-v0.7.7-OneClick.zip`：带 `reeden-kobo/` 顶层目录的一键安装包及源码。
- `Reeden-Kobo-v0.7.7-Source.zip`：同一标签提交的源码快照。
- `COMMIT.txt`：精确源提交。
- `SHA256SUMS`：两个 ZIP 与提交文件的 SHA-256 校验值。

两个 ZIP 均由精确标签提交的 `git archive` 生成。发行流水线执行 Python 回归、三平台双 Python 版本安装卸载检查、ARMHF 重建与预编译件逐文件比较、Linux C 回归及 QEMU 合成测试后发布。
