# Reeden Kobo v0.7.8-community.1（社区实验版）

基于 [SSNQ/reeden-kobo v0.7.8](https://github.com/SSNQ/reeden-kobo/releases/tag/v0.7.8)，合入原作者的资源恢复修复，同时保留社区的一键更新、菜单保护和异常恢复改进。原作者署名与许可保留；不是 Reeden、Kobo 或 SSNQ 的官方发布。

## 下载和更新

1. 下载 **Reeden-Kobo-Adapter-v0.7.8-community.1-OneClick.zip**，完整解压到新文件夹。不要用旧文件夹的更新入口，也不要只下载一个脚本。
2. 电脑需 Python 3.10+，Kobo Clara Colour（393）需已安装 NickelMenu。先备份书库和笔记，退出 Reeden，USB 连接并在 Kobo 上点「连接」。
3. 已经安装过：MacBook Air / Mac 双击 **一键更新-macOS.command**；Windows 双击 **一键更新-Windows.bat**；Linux 运行 `sh 一键更新-Linux.sh`。首次安装选择对应的「一键安装」。
4. 等待完成后安全弹出。更新会保留原阅读数据和旧版备份，自动生成资源恢复归档，不需手工补文件。

## 本版改动

- 合入上游的缺失资源恢复：本地恢复归档经过校验，仅补回缺失的界面和核心资源，不覆盖已存在的文件，不改用户书库、笔记和设置。
- 每次启动重新校验安装；恢复包损坏、程序文件缺失或已有文件内容不符时仍拒绝启动，不跳过校验放行。
- 保留社区的自定义菜单保护，并结合上游的平台写入同步；安装确认时输入「取消」不写设备。
- 保留社区的异常会话恢复、充电锁屏心跳、封面提交失败处理和 Wi-Fi 交还提示。旧会话未恢复完成时，不继续资源修复。
- 自检和两个组包入口使用一致的社区版本号；同步中文使用说明。

## 测试和限制

发布流程运行 Windows/macOS/Linux 模拟 USB 安装、更新和卸载，Linux 资源与会话恢复故障注入，ARMHF 重建与预编译件逐字节比对，C 回归及 QEMU 检查。对应结果见 [Actions](https://github.com/Northfish0311/reeden-kobo/actions/workflows/ci.yml)。

**本社区整合版仍待真实 Kobo 验收。** SSNQ 已记录的 v0.7.8 实机恢复测试不代表本分支已完成实测。每次启动的完整校验可能增加等待，实际用时、锁屏唤醒及续航仍需测试；本次未修改翻页显示算法，也不宣称消除残影。支持范围不扩大，原项目已测固件为 4.46.23836。

官方核心与本地恢复归档不随本公开 ZIP 分发，由安装器在用户电脑上使用校验后的官方包生成。安装仍需受支持的 Kindle 核心 1.43.2+791 或 1.43.1+780，780 完整资源来源校验的限制不变。

完整步骤见[中文安装与更新说明](https://github.com/Northfish0311/reeden-kobo/blob/main/docs/安装与卸载.md)。`Source.zip` 是源码快照，`COMMIT.txt` 和 `SHA256SUMS` 用于核对来源与下载完整性。
