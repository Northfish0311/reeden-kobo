# Reeden Kobo v0.7.6 (Experimental)

修复官方包下载中断、缓存和候选包选择，以及设备端卸载失败后的恢复。支持范围仍为 Kobo Clara Colour（393）/ 固件 4.46.23836，电脑需 Python 3.10+，设备需 NickelMenu。

- 官方下载写入独立临时文件，完整解包及白名单验证成功后原子替换缓存；有限重试，失败保留原缓存并清理半包。
- 自动发现逐个验证候选，损坏或不支持的包不再遮挡后面的有效包。`--download-official` 明确强制联网，失败不会静默使用旧包。
- 791 官方核心使用纯文本 SHA-256 清单核验完整文件集合和每个文件。核心不随本项目分发。
- 780 保留原两库 SHA-256 白名单，补充版本元数据和资源结构检查；由于未取得官方原包，不能声称完成 780 全文件校验。官网文档与官方 GitHub 发布列表未提供可验证的 Kindle 历史包，未加入猜测的回退 URL。若 latest 将来不受支持，请显式提供已支持的官方包。
- 设备端卸载先移动并保存全部程序与阅读数据，成功后再处理自有菜单；移动失败保留入口，菜单清理失败报告保存路径。

安装：完整解压 `Reeden-Kobo-Adapter-v0.7.6-OneClick.zip`，运行对应平台脚本。已有安装先退出 Reeden，使用 `--upgrade` 保留数据升级。

翻页动画、淡残影和实验功能的支持边界沿用 v0.7.5。本次没有新的真机验收。

附件由精确标签提交的 `git archive` 生成。`COMMIT.txt` 记录源提交，`SHA256SUMS` 校验两个 ZIP 与提交文件。
