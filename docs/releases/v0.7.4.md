# Reeden Kobo 0.7.4 — Experimental / 安装器安全更新

仅支持 Kobo Clara Colour（393），已测固件 4.46.23836；电脑需 **Python 3.10+**，设备需已安装 NickelMenu。下载 `Reeden-Kobo-Adapter-v0.7.4-OneClick.zip`，完整解压后使用三平台一键安装/升级/卸载脚本。官方核心白名单仍为 Kindle 1.43.2+791 / 1.43.1+780，闭源核心由用户自行提供或安装器从官网获取并校验。

## 安全修复

- ZIP / Debian TAR 先核验完整路径布局，再写载荷；拒绝绝对路径、上级目录越界、Windows 盘符/反斜杠/ADS/设备名、大小写冲突、特殊文件和不安全链接，防止目标目录已有符号链接将读写导向根目录外。
- Debian 链接仅在解包根目录内复制为普通文件，不创建宿主链接；合法长链接链可以解析。ar 负长度、截断、重复数据成员拒绝处理。手动提供的已解压官方目录也拒绝链接和特殊文件。
- 增加恶意路径、链接和归档格式回归，并在三平台 Python 3.10/3.12 CI 运行；真实官方包与固定依赖的兼容组包检查通过。此前的 SHA-256 白名单仍然保留，不以路径检查替代来源校验。

## 项目完善

- 首页明确非官方与 Experimental、备份要求、Python 版本和当前下载地址；增加真实设备首页截图、兼容表及实机/模拟测试边界。
- 新增 SECURITY.md、私密漏洞报告和 Bug 表单；补充全部公开历史、发布附件与本地备份扫描结果。
- 经明确授权，将旧公开提交/标签的个人邮箱改为 GitHub noreply，历史文件树保持不变。旧 Release 附件不重写，其 COMMIT/ZIP 注释可能仍指清理前的标识；已有克隆须重新同步。旧缓存和下载无法撤回。
- Debian Bullseye 免费 LTS 已结束，公开依赖维护评估；本版未升级固定运行库、官方 glibc、引擎或 Kobo 内核。不得将 SHA-256 校验写成持续安全维护。

## 升级提示

旧版免认证 SSH 不会因为替换安装文件自动停止。曾开启 v0.7.0 诊断 SSH 的用户，应退出 Reeden，停止监听并结束已有会话，或重启设备，再按当前密钥认证说明配置。电脑 USB 卸载不能关闭设备内存中的服务。

新安装请勿使用 v0.7.3 及以前安装器，也不要使用不可信来源的官方 ZIP。现有用户先退出后使用 `--upgrade` 保留数据升级；安装写入期间不要拔线。默认卸载保留整份备份，可明确确认后删除当前安装及阅读数据；旧备份与自定义菜单不自动删除。

阅读、刷新、灯光与电源功能延续 0.7.2，本轮没有新的隔夜休眠、实际续航或其他固件验收。运行需要硬件与 root 权限，不能保证所有故障均可恢复。兼容范围、依赖风险与原始设备验收见仓库文档。
